⚙️ Backend do Sistema (backend)

📝 Descrição do Projeto


A pasta backend contém a lógica principal do sistema responsável por processar informações e integrar os diferentes componentes do projeto.


O backend atua como intermediário entre o usuário e o banco de dados, garantindo que as tarefas enviadas pelo Web Chat sejam interpretadas corretamente e armazenadas de maneira estruturada.


Nesta parte do projeto estão os scripts responsáveis por:


Processar dados recebidos do usuário

Organizar informações das tarefas

Enviar dados para o banco de dados

Integrar o sistema com os fluxos de automação



🚀 Tecnologias Utilizadas

Python – Linguagem utilizada para a lógica do sistema.

APIs e Webhooks – Comunicação entre diferentes serviços.

Integração com n8n – Automação do processamento das tarefas.

📊 Resultados e Aprendizados


Durante o desenvolvimento do backend foi possível compreender melhor a estrutura de sistemas que processam dados em tempo real.

Principais aprendizados:

1.Estruturação da lógica de processamento de dados.

2.Integração entre serviços utilizando APIs.

3.Organização de código para facilitar manutenção e expansão do sistema.


🔧 Como Executar

1.Clone o repositório.

2.Acesse a pasta backend.

3.Instale as dependências necessárias.

4.Execute o script principal responsável pelo processamento das tarefas.
