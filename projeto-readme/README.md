📋 Organizador Inteligente de Tarefas

📝 Descrição do Projeto

Este repositório apresenta o projeto Organizador Inteligente de Tarefas, desenvolvido com o objetivo de auxiliar usuários na organização de suas atividades diárias por meio de automação e integração entre diferentes tecnologias.

O sistema permite que o usuário registre tarefas de forma simples através de um Web Chat, enquanto os dados são processados automaticamente por fluxos no n8n e armazenados em um banco de dados no Firebase.

A proposta do projeto é demonstrar, de forma prática, como é possível integrar ferramentas modernas para criar uma solução funcional de gerenciamento de tarefas automatizado.

O funcionamento geral do sistema ocorre da seguinte forma:

O usuário envia uma tarefa pelo Web Chat

A mensagem é recebida pelos fluxos de automação no n8n

O sistema processa e organiza os dados automaticamente

As informações são armazenadas no Firebase para consulta futura

Esse fluxo garante uma experiência simples para o usuário, enquanto o sistema realiza todo o processamento em segundo plano.

🚀 Tecnologias Utilizadas

Interface: Web Chat

Automação: n8n

Banco de Dados: Firebase

Backend: Scripts de processamento e integração

Comunicação: APIs e Webhooks

📂 Estrutura do Projeto

O repositório está organizado em pastas para facilitar a navegação e compreensão de cada parte do sistema:

docs → Contém a documentação do projeto, incluindo explicações, diagramas e materiais de apoio

backend → Responsável pela lógica do sistema e processamento das tarefas

database → Estrutura e configuração do banco de dados (Firebase)

fluxos → Fluxos de automação criados no n8n

Cada pasta possui um README específico explicando detalhadamente sua função dentro do projeto.

O desenvolvimento deste projeto proporcionou uma melhor compreensão sobre integração de sistemas e automação de processos.

Principais aprendizados:

Integração entre diferentes tecnologias (Web Chat, n8n e Firebase)

Estruturação de um sistema completo dividido em partes

Automação de tarefas utilizando ferramentas low-code

Organização de projetos para fins acadêmicos e profissionais

O projeto demonstra como é possível criar soluções eficientes utilizando ferramentas acessíveis e bem integradas.

🔧 Como Executar

1.Clone o repositório

2.Configure o banco de dados no Firebase

3.Importe os fluxos no n8n

4.Execute o backend (se necessário)

5.Utilize o Web Chat para enviar e gerenciar tarefas
