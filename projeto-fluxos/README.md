🔄 Fluxos de Automação (fluxos)
📝 Descrição do Projeto

A pasta fluxos contém os fluxos de automação criados na ferramenta n8n, responsáveis por processar as tarefas enviadas pelos usuários.

Os fluxos funcionam como um sistema de automação que recebe mensagens do Web Chat, interpreta os dados enviados e realiza ações automáticas, como armazenar informações no banco de dados.

Esses fluxos são responsáveis por conectar diferentes partes do sistema, permitindo que a aplicação funcione de forma integrada.

🚀 Tecnologias Utilizadas
n8n – Ferramenta de automação de processos.
Webhooks – Recebimento de dados enviados pelo chat.
Integração com Firebase – Armazenamento das tarefas.
📊 Resultados e Aprendizados

A utilização do n8n permitiu criar um fluxo automatizado para processar informações sem necessidade de intervenção manual.

Principais aprendizados:

1.Criação de automações utilizando ferramentas low-code.
2.Integração entre serviços através de webhooks.
3.Estruturação de fluxos de dados entre diferentes sistemas.

🔧 Como Executar
1.Instale ou acesse uma instância do n8n.
2.Importe os arquivos de fluxo presentes nesta pasta.
3.Configure as integrações necessárias.
4.Execute os fluxos para iniciar a automação do sistema.
